# Not claimed

This draft does not do any of the following.

- It does not diagnose anyone.
- It does not interpret drawings, words, photos, or silence.
- It does not claim to know what a person feels.
- It does not offer treatment, therapy, or clinical care.

A theme tag is a label the person confirms or edits. It comes from the prompt, not from a reading of the drawing.

Weekly noticing counts theme tags and then asks: "What do you make of that?"

The draft does not answer that question. A note typed there is stored and not analyzed.

Leaving a drawing does not share a name or the words. Only the drawing image can be marked to leave, and that mark stays on this device. A received sample is a local picture with the same tag. It is not a message from another person.
